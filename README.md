# Workout Schedule Builder

This is a React app that helps college students create a weekly workout schedule. The user chooses a fitness goal and the days they are available. The app then creates a workout plan based on their choices.

## Features

- Choose a fitness goal: Build Muscle, Lose Weight, or Stay Active
- Select available workout days
- Create a personalized weekly workout schedule
- Get different workout suggestions depending on the selected goal

## Technologies Used

### React

I chose React because it makes interactive apps easier to build. I used React state to update the workout schedule when the user selects their goal and available days.

### JavaScript

I used JavaScript for the app logic, including saving the selected goal and generating the schedule.

### CSS

I used CSS to create the colors, buttons, cards, spacing, and mobile layout.

### Node.js and npm

I used Node.js to run the app locally and npm to install packages and start the project.
