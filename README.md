# Workout Schedule Builder

This is a React app that helps college students create a simple weekly workout schedule. The user chooses a fitness goal and the days they are available to work out. The app then creates a workout plan based on their choices.

## Features

- Choose a fitness goal: Build Muscle, Lose Weight, or Stay Active
- Select the days you are available to work out
- Create a personalized weekly workout schedule
- Get different workout suggestions depending on the selected goal
- Works on smaller screen sizes too

## Technologies I Researched and Used

### React

I chose React because it makes it easier to build interactive user interfaces. React uses components and state, which helped me update the workout schedule after the user selected their goal and available days.

One advantage of React is that it updates the page without needing to reload it. One disadvantage is that it takes time to learn React concepts such as state and event handling.

### JavaScript

I used JavaScript for the app logic. It keeps track of the selected goal and workout days, then creates a schedule with different workout suggestions.

### CSS

I used CSS to design the app. CSS was used for the colors, buttons, cards, spacing, and mobile layout.

### Node.js and npm

I used Node.js to run the React app on my computer. I used npm, the package manager, to install the React project dependencies and run the app with `npm start`.
